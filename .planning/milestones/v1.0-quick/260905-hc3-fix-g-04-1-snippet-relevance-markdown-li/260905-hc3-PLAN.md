  <action>
    Create src/sif/search/term_match.py exposing: term_matches(text, term) -> bool; count_matches(text, term) -> int; distinct_terms_matched(text, terms) -> int; find_first_match(text, terms) -> tuple[int, int] | None (earliest start across terms, match length included). All functions are case-insensitive internally.

    Compile-once cache: a single @lru_cache(maxsize=512) helper _compile(term) returning re.Pattern[str] | None, so repeated queries never recompile. Branch on term.isascii():

    ASCII pure-alphabetic terms (term.isalpha()): compute a light stem — if len(term) > 4 and term ends with "ies", replace with "y"; otherwise strip the first applicable trailing suffix from ("ing", "ed", "es", "s", "e") only when the remaining base has length >= 3. Build pattern: custom lookaround boundary (?<![a-z0-9]) + re.escape(base) + optional suffix group (?:s|es|ed|ing|e)? + (?![a-z0-9]) compiled with re.IGNORECASE. Use these lookarounds instead of \b because Python \b treats underscore as a word character; the lookarounds make each snake_case segment individually matchable (required for SIF_CHUNK_OVERLAP-style rows) while still preventing matches strictly inside a longer alphabetic run (the notable/table false positive from G-04-1). The optional suffix group means an over-stripped base still re-matches the original surface form.

    ASCII terms containing non-alphabetic chars (hyphens, digits, dots — e.g. "sqlite-vec", "3.5"): no stemming; re.escape the whole term; attach the (?<![a-z0-9]) lookbehind only when the first character is alphanumeric, and the (?![a-z0-9]) lookahead only when the last character is alphanumeric (a trailing "c++" style char gives no reliable boundary).

    Non-ASCII terms (CJK — term.isascii() is False): no regex. Lowered-plain-substring path: boolean gate passes when the full run is present, OR when the count of distinct term characters present in text reaches max(2, number_of_distinct_term_characters // 2) — this is the per-character fallback credit that lets 向量搜索 highlight 向量检索 while a lone shared character still fails. find_first_match for CJK returns the full-run position when present, else the first position of any term character. count_matches returns the full-run count, or the distinct-characters-present count when the run is absent (used as secondary scoring credit).

    Code style per CLAUDE.md: full type annotations (disallow_untyped_defs), line length 100, module docstring, keep every function mccabe <= 10 by delegating branch logic to small helpers.
