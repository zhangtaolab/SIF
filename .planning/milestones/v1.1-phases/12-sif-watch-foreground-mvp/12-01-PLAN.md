| Boundary | Description |
|----------|-------------|
| filesystem events -> watch process | externally-shaped input: arbitrary/pathological filenames, non-UTF8 bytes, storm volumes |
| watch process -> sif.db | writes through repositories (parameterized SQL) on the factory connection |
| watch process -> logs/stdout | rendered output must never carry document content |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-12-01 | Tampering | watcher event intake (pathological/non-UTF8 names) | medium | mitigate | `os.fsdecode` via `_event_path`, `Path.resolve()`, fnmatch shared predicate, parameterized repository SQL only — no shell interpolation, no eval |
| T-12-02 | DoS | event storm -> unbounded queue/memory | medium | mitigate | EventDebouncer coalesces per quiet window; fold dedupes to a path SET per batch; bounded single-drain shutdown flush (D-14 landed in 12-02) |
| T-12-03 | Information disclosure | logs/CLI output carrying document content | medium | mitigate | log paths at debug only, never parsed content; document content never Rich-markup-rendered (locked decision, D-13) |
| T-12-04 | Tampering | symlinked watch roots escaping intended roots | medium | mitigate | schedule only `Path(collection.path).resolve()` of registered collections, recursive under that root; never watch broader (D-01) |
| T-12-05 | DoS | missing root misread as mass deletion destroying the index | high | mitigate | D-11 guard at the top of update_collection AND update_paths: warn + `missing <name>` event + zero result, never sweep — regression-tested against the verified latent bug |
| T-12-SC | Tampering | dependency range change (pip/uv) | high | mitigate | No new package enters the environment: watchdog is a locked v1.0 dependency, only its range is tightened to &gt;=4.0.0,&lt;7.0.0; RESEARCH.md Package Legitimacy Audit table exists and dispositions the SUS heuristic flag as a false positive (source-level inspection of installed 6.0.0, ~15-year-old active project) — no blocking checkpoint per the audit's documented approval |
