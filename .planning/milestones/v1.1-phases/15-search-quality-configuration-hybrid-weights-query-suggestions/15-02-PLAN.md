## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| user query string → suggestion engine | untrusted strings flow into tokenization, difflib, and (on re-query) FTS MATCH |
| query strings → query_log table | personal search strings persisted locally |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-15-03 | Tampering | suggestion engine → FTS MATCH | medium | mitigate | Vocab/query terms re-enter search exclusively via _sanitize_term/_build_fts_query quoting (bm25.py:16-33) — never hand-built MATCH strings; repository SQL fully parameterized (ASVS V5) |
| T-15-04 | Information Disclosure | query_log (local personal data) | medium | mitigate | Local-only table in sif.db; stores query string/result count/collections only — never document content (D-08); SIF_QUERY_HISTORY_ENABLED=0 global opt-out + trim cap bound the retained surface |
| T-15-05 | DoS | unbounded query_log growth | low | mitigate | Trim-in-write cap (D-09, default 500, ge=1) — the table never grows unboundedly; no cleanup ritual needed |
| T-15-SC | Tampering | package installs | high | accept | No package installs in this plan — difflib/bisect/sqlite3 are stdlib; zero new runtime dependencies (locked) |
</threat_model>
