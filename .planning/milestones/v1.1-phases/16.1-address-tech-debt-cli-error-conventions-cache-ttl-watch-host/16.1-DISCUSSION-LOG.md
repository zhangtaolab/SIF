## Cache TTL read path

| Option | Description | Selected |
|--------|-------------|----------|
| Instant-compare in get() | Fetch row by key, parse expires_at, compare instants; legacy naive-local strings interpreted as system-local via astimezone — exactly clear_expired()'s locked WR-09 semantics; one shared expiry helper; no migration | ✓ |
