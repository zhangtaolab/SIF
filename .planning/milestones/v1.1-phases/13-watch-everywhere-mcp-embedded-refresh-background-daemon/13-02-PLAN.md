## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| PID file on disk (any local process can write it) -> --stop signal decision | the file is untrusted input: parse defensively, corroborate before any signal |
| daemon log file (user-writable dir) | sif-generated content only; 0644 in a user-owned dir matching the launchd StandardOutPath contract |
| signals (SIGTERM from --stop, SIGKILL from SC4) -> daemon shutdown path | bounded graceful path; kernel-released flock keeps arbitration correct on SIGKILL |
