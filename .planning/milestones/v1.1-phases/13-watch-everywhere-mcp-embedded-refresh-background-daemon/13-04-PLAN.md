<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| install flags + resolved paths -> generated plist/unit -> OS service manager | everything embedded in ProgramArguments/ExecStart derives from flags and resolved absolute paths — no user free-text reaches a shell |
| artifact destinations (~/Library/LaunchAgents, ~/.config/systemd/user) | user-owned dirs; only our own label's file is written or removed |
| manager binaries invoked via subprocess | explicit argv only; missing-binary and failure paths must degrade to friendly errors |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-13-10 | Elevation | shell injection through install flags/paths into launchctl/systemctl | high | mitigate | Explicit argv lists exclusively — never shell=True, never interpolated command strings (D-12); plist values via plistlib (typed, escaped); unit ExecStart from validated absolute paths; source assertion in acceptance criteria |
| T-13-11 | Tampering | pre-planted file/symlink at the plist/unit destination swapped into service position | medium | mitigate | Atomic write-temp-then-rename with 0644 into user-owned dirs; only our own label's filename is ever written or removed; no world-writable creates |
| T-13-12 | Elevation | another local user planting/capturing the service definition | low | mitigate | Destinations are user-scoped (~Library/LaunchAgents, ~/.config/systemd/user) with default umask and explicit modes; single-user local tool per REQUIREMENTS positioning |
| T-13-13 | DoS | re-install over an already-bootstrapped label leaves partial/stale service state (Pitfall 5) | low | mitigate | Idempotent-ish install: bootout-then-bootstrap on conflict, post-install verify via launchctl print / is-active, output names the artifact path so stale-config symptoms are diagnosable |
| T-13-SC | Tampering | package installs introducing malicious dependencies | high | mitigate | zero-new-deps lock (plistlib/subprocess are stdlib per research Standard Stack); no install steps in this plan |
</threat_model>
