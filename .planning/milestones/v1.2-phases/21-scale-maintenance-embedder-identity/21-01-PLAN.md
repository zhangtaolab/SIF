<objective>
Build the embedder identity and role-aware embed foundation: a persisted, deterministic `index_meta` identity record with a mode-aware comparison, a prompt-scheme resolver, role-explicit embed methods on the concrete embedders and the manager, and prompt/revision-aware cache buckets that leave the default Qwen3 path byte-identical.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| model settings -> identity record | User-controlled model name/type/api_base/prompt names become persisted provenance |
| model metadata -> revision | Third-party model configs and GGUF files feed the revision field |
| embedding backend -> cache | Model output crosses into the persistent embedding cache |
| identity JSON in index_meta -> callers | The stored record is read and parsed by every host |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-21-01 | Tampering | EmbeddingManager cache write/read | high | mitigate | Validate count, finiteness, and dimension before `cache.set` and on cache read; invalid entries are recomputed and overwritten so a poison batch cannot persist (Task 3). |
| T-21-02 | Tampering | identity.from_json / read_identity | medium | mitigate | Defensive parse returns None with one warning on malformed JSON, non-object payloads, or missing fields; no caller crashes on a corrupt kv row (Task 1). |
| T-21-03 | Elevation of Privilege | revision provenance | medium | mitigate | Revision comes only from an in-memory transformers commit hash or a local GGUF file SHA-256; ModelScope `.msc` manifests are never unpickled (Tasks 1-2). |
| T-21-04 | Spoofing | prompt name resolution | low | accept | Prompt names are local settings plus a fixed table; the model's own `prompts` dict is the authority and an unknown name fails loudly, so a typo cannot silently change vectors. |
| T-21-SC | Tampering | npm/pip/cargo installs | high | mitigate | No package install occurs in this phase (D-20); package-legitimacy gate is a no-op and the plan adds no dependency. |

## Residual Risk

A ModelScope local snapshot exposes no revision (`None`), so a re-downloaded model at the same name is indistinguishable from the original. Recorded in the identity as honest `revision: null`; the `--force` certification path is the only remedy. Accepted as an explicit limitation (research A2).
