  <action>
    Create `src/sif/indexing/breadcrumb.py` as a pure, I/O-free helper in the chunker style. Define a compiled heading pattern matching a line that starts with one to six `#` characters, whitespace, and a non-empty label. Implement `breadcrumb_embed_texts(title: str, chunks: Sequence[DocumentChunk], separator: str = " > ") -> list[str]`. Walk chunks in order; inspect the first non-empty line of each chunk; when it is a heading, set the current heading to its stripped label; build the path from the stripped title when non-empty plus the current heading when present and different from the title; prepend the joined path and a blank line to the chunk content; when the path is empty return the chunk content unchanged. Return a parallel list with exactly one entry per chunk and never mutate `DocumentChunk`.

    Extend `src/sif/config/settings.py` Chunking settings with `embed_breadcrumb: bool = Field(default=False, description="Prepend the document title and current heading path to each chunk's embedding text; stored content and full-text search stay unchanged")` placed after `chunk_overlap`, so the env var is `SIF_EMBED_BREADCRUMB`.

    Extend `StreamingEmbedWriter.__init__` with a keyword-only `embed_breadcrumb: bool = False` parameter after `write_identity`, store it, and change `embed_document` to compute one `embed_texts` list per document: `breadcrumb_embed_texts(doc.title, chunks)` when enabled, otherwise `[chunk.content for chunk in chunks]`. Slice that list per batch using the batch offset and pass the slice to `self._manager.embed_documents`. Keep the delete-before-insert transaction, the identity claim, the systemic-error translation, and the persisted `chunk.content` exactly as they are. Pass `embed_breadcrumb=settings.embed_breadcrumb` at the `index embed` writer construction in `src/sif/cli/commands/index.py` and at the watcher session's writer construction in `src/sif/indexing/watcher.py`.

    Tests: `tests/unit/indexing/test_breadcrumb.py` covers an H1-first document, an H2-first document, an H1-per-section document where each section heading supersedes the previous one, a document with no headings (title-only path), a CJK heading, an empty title (content-only), title equal to the first heading (deduplicated once), a sub-chunk without a heading inheriting the prior section heading, the separator, the output length equalling the chunk count, and input chunks remaining byte-identical. Extend `tests/unit/indexing/test_embed_writer.py` with: default-off calls the manager with exactly the chunk content strings and persists identical content; breadcrumb-on calls the manager with strings beginning with the title path while the persisted `DocumentChunk.content` and the chunks FTS rows stay identical; a multi-batch document keeps batch alignment (each batch receives the matching slice); the cache-key consequence is demonstrated by asserting the manager received different strings with the flag on versus off. Extend `tests/unit/config/test_settings.py` with the false default and `SIF_EMBED_BREADCRUMB=1` parsing.
