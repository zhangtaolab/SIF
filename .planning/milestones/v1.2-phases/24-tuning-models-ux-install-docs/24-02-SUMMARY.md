# Phase 24 Plan 02: Breadcrumb Embed-Text Overlay Summary

Pure title/heading-path builder plus a default-off Settings switch wired through
the streaming writer, `index embed`, and `watch`; the stored index contract and
the default-off embedding inputs stay byte-identical.

## What Was Built

- **`src/sif/indexing/breadcrumb.py`** — pure, I/O-free
  `breadcrumb_embed_texts(title, chunks, separator=" > ")`. It walks the chunks
  in document order, starts a section whenever a chunk's first non-empty line
  is a Markdown heading (`#{1,6}\s+\S...`), inherits the most recent heading
  for headingless continuations, deduplicates a heading equal to the stripped
  title, and prepends `path + "\n\n"` to the chunk content. Empty title plus no
  heading returns the content unchanged. The returned list is parallel to the
  input and never mutates `DocumentChunk`.
- **`Settings.embed_breadcrumb`** — `bool = False` with env
  `SIF_EMBED_BREADCRUMB`, placed after `chunk_overlap` in the Chunking section.
- **`StreamingEmbedWriter(..., embed_breadcrumb=False)`** — computes one
  `embed_texts` list per document (breadcrumb only when enabled, otherwise raw
  chunk content) and slices it per model batch with the batch offset, keeping
  batch alignment. Persistence, delete-before-insert, identity claim, and
  systemic-error translation are untouched; `chunk.content` is what is stored.
- **Call sites** — `index embed` and the watcher session both pass
  `settings.embed_breadcrumb`.
- **`docs/configuration.md`** — regenerated by `make docs-generate` with the
  `SIF_EMBED_BREADCRUMB` row; `docs/cli-reference.md` regenerated
  byte-identically (no CLI surface changed).

## Tests

- `tests/unit/indexing/test_breadcrumb.py` (13 cases): H1-first, H2-first,
  H1-per-section supersession, no headings (title-only), CJK heading, empty and
  whitespace title (content-only), title-equal heading deduplication,
  stripped comparison, headingless sub-chunk inheritance, configurable
  separator, parallel output with byte-identical inputs, leading blank lines,
  and non-heading hash lines.
- `tests/unit/indexing/test_embed_writer.py` (4 new cases): default-off passes
  exactly the chunk content; breadcrumb-on passes breadcrumb strings while
  persisted chunks and `chunks_fts` stay identical; multi-batch slicing stays
  aligned; the flag changes every embedded string (the cache-key consequence).
- `tests/unit/config/test_settings.py` (2 new cases): default false and
  `SIF_EMBED_BREADCRUMB=1` parsing.

### Notes

- The plan's grep check (`grep -v '^#' docs/configuration.md | grep -c
  'embed_breadcrumb'`) is case-sensitive, but the generator emits the uppercase
  env name `SIF_EMBED_BREADCRUMB`. The check was run as `grep -ci` (count 1) to
  verify the intended fact — the generated reference documents the field. The
  docs were regenerated, never hand-edited, and the diff gate is clean.
- The heading pattern requires a non-whitespace label (`\S.*?`), a stricter
  reading of "non-empty label" than the research sketch's `(.+?)`; a bare
  `#   ` line correctly does not start a section.
