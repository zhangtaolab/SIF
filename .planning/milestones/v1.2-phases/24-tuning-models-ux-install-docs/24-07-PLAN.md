Purpose: Determine with measured evidence whether a title/heading breadcrumb adds retrieval value beyond the already-indexed title, without ever changing the stored index contract on a rejection.
Output: `duplicate_metrics`, `decide_breadcrumb_default`, `scripts/breadcrumb_eval.py`, and unit coverage for the dry-run plan, identity gate, duplicate aggregation, per-leg veto, and artifact guard.

The production breadcrumb path and the Settings switch live in plan 02, which this plan depends on.
