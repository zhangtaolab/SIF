<objective>
Close UAT gap G-19-8 (UAT test 8; review item IN-09) by making the promise of `sif search search --min-score` hold exactly: "Keep matches scoring at least this value" now keeps a row whose displayed score equals the threshold to the last bit.

The gap. On an isolated index of `tests/fixtures/bench/corpus`, 40 of 84 matching rows disappeared when `--min-score` equalled their own displayed score; `sif search search "kelpri protocol" -c bench-fixture -n 10` returned `Kelpri Protocol Notes` with score `0.8942969341194331`, and the same command with `--min-score 0.8942969341194331` returned nothing.

The cause. The SQL predicate compares the raw bm25 value with a bound computed in Python from the threshold. That bound is not the exact floating-point inverse of the displayed-score map `|bm25|/(1+|bm25|)`, so for about half of the double values it rounds to the wrong side of the row's own value. Plan 19-12's second truth records this boundary as a property; the operator authorised that plan and its boundary has now failed UAT.

The fix (the orchestrator's decision D-1 for this round). The predicate compares the displayed score itself, computed in SQL from the same weighted expression that is projected as `m.score`, and binds `min_score` as it was given. SQLite and Python round that division the same way: the planner checked 30,211 values on 2026-11-26 and found no difference for any finite non-zero double (signed zero differs in its sign bit only, and infinity yields NULL in SQL; neither can come from a matching row). One test pins this agreement over 100,189 values, so a platform where it fails says so.

What is kept. The predicate is omitted when `min_score` is not above 0, which also covers NaN: a NaN reaches SQLite as NULL, and the comparison would then be NULL and drop every row. The predicate stays a bound parameter in the outer WHERE clause of both SQL branches, ahead of the metadata filter suffix and of `LIMIT ? OFFSET ?`, so the locked rule that BM25 `min_score` is applied before pagination holds and pages have no holes with global ranks (CONTEXT locked upstream, D-06). A `min_score` of 1 or more keeps no row by arithmetic, with no special bound. Scores, ranking and the rows kept at any other threshold do not change.

The threshold helper. `bm25_rank_threshold` was added by plan 19-12, is unreleased (`## [Unreleased]` in the changelog), and its only caller is the line this plan replaces (`grep -rn 'bm25_rank_threshold' src tests` names four lines: its definition, that call, and its import and table test in `tests/unit/search/test_bm25.py`; nothing under `docs/` or `scripts/` names it). It is removed with its table test. Two records of plan 19-12 are superseded and stay unedited: the boundary sentence of its second truth, and the helper's export in its artifact row.

Reversibility. The change is one predicate in one function. No score, no ranking and no stored data change, the bound it replaces was never released, and undoing it is a one-commit revert, so the task that makes it is rated `reversible` and carries no decision checkpoint.

Not changed here, still open in the UI review: R2-04, a score copied from the table, CSV, Markdown or XML output, which print four decimals, can round above a row's exact score and drop that row (the fix is exact for the value given; copy the score from `--json`); and R2-01, the band in which a BM25 threshold bites is not discoverable. The chunk searcher `search_chunks` keeps its post-window filter (IN-05).

Cascade. Executing this plan re-stales the verifications of Phases 17, 18, 20, 21, 22 and 24; all of them already read `stale` after the first round, and Phase 19 is re-verified after this round.

Decision coverage: keeps the CONTEXT locked-upstream rule that BM25 `min_score` is applied before pagination and D-06 true, and amends the fourth truth of `19-05-PLAN.md` in place with a dated note, as plan 19-12 did.

Output: the exact predicate without the converted bound, re-pinned and new tests with their red runs on record, the before-and-after evidence of the fix in a committed artifact, and the written contract (changelog entry and amended truth).
