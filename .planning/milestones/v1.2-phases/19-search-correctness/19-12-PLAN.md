<objective>
Close UAT gap G-19-2 (UAT test 2) by implementing option `monotone-map` chosen at the 19-11 decision checkpoint: make the displayed BM25 score rise with relevance and make `--min-score` keep the stronger matches wherever the BM25 searcher applies it.

Why this plan runs only on that choice. The behaviour is Phase 19's own recorded contract: the fourth truth of `19-05-PLAN.md` names the bound `1 - 1/min_score` with `rank >= threshold`, and tests pin it. Changing it alters a public output contract (every BM25 score across CLI output formats and MCP `lex_search`), so the operator decided at the blocking checkpoint in plan 19-11; this plan is written for the recommended option only, and its first task halts unless that option is on record in both places.

What changes. The displayed score becomes `|bm25|/(1+|bm25|)` and the bound becomes `-M/(1-M)`, an upper comparison on the non-positive bm25 value. One searcher applies the threshold for three commands: `sif search search --min-score` and MCP `lex_search` now keep the stronger matches, as their help text says; `sif query --min-score` and the `min_score` of MCP `query` change in their BM25 leg for the same reason (truth 8); `sif search vsearch --min-score` and MCP `vec_search` filter on vector similarity and do not change. Ranking is unchanged wherever the same rows reach fusion: RRF ranks by list position and only copies the BM25 score.

Invariants kept from Phase 19 and CONTEXT: the filter still runs before LIMIT/OFFSET (the locked upstream rule, CONTEXT lines 13 and 46), every value is bound, pages have no holes, `min_score` 0 omits the filter, and global rank numbering is unchanged (D-06). Observation only, out of scope: `query` scores without a breakdown are RRF values around 0.01 to 0.03, so the same numeric threshold means something different there.

Decision coverage: keeps D-06 and the CONTEXT locked-upstream min_score ordering rule true; amends the one 19-05 truth that recorded the old bound, in place and with a dated note.

Output: the monotone score and matching bound, re-pinned and new tests (the hybrid BM25 leg included), a regenerated SC1 golden with its rationale, the after half of the evidence artifact, and the written contract (help text, generated reference, changelog, benchmarking notes, amended truth).
