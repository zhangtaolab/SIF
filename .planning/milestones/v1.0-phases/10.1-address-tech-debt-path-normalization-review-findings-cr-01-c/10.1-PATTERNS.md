    def _fts_update_trigger_is_legacy(self, trigger_name: str, fts_table: str) -> bool:
        """Check if an existing FTS sync trigger uses the broken direct-UPDATE form. ..."""

### `src/sif/cli/commands/search.py` — CR-02 (utility, transform)

**Analog:** itself — `format_results_xml`, lines 104-121. Add `_xml_sanitize(...)` wrapping every `xml_escape(...)`/`quoteattr(...)` argument:

```python
def format_results_xml(results: list[Any], query: str) -> str:
    """Format results as XML."""
    lines = ['<?xml version="1.0" encoding="UTF-8"?>', f"<search query={quoteattr(query)}>"]
    for r in results:
        ...
        lines.append(f"    <title>{xml_escape(str(_field(r, 'title')))}</title>")
        lines.append(f"    <path>{xml_escape(str(_field(r, 'path')))}</path>")
```

Sanitizer (XML 1.0 Char production transliterated; strip exactly `#x0-#x8 | #xB | #xC | #xE-#x1F | surrogates | #xFFFE-#xFFFF`; keep `#x9 #xA #xD`; do NOT strip `#x7F-#x9F`):
```python
_XML_1_0_INVALID = re.compile("[\x00-\x08\x0b\x0c\x0e-\x1f\ud800-\udfff￾￿]")

def _xml_sanitize(text: str) -> str:
    """Strip code points forbidden by XML 1.0 Char production (keep #x9/#xA/#xD)."""
    return _XML_1_0_INVALID.sub("", text)
```
Keep `xml_escape`/`quoteattr` — they handle `<>&'"` correctly; only forbidden code points are the gap.
