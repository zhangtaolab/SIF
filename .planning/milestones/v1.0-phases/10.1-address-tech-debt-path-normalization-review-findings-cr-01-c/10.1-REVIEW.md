## Info

### IN-10: Test-count claims are stale in the same commit that introduces them

**File:** `docs/testing.md:4` (also `:91,:93`)
**Issue:** The diff adds "1000 tests in total" (line 4) and "960 tests" for
`unit/` (line 93). Actual collection at this commit: **1011 total, 971 unit**,
18 integration, 13 docs, 9 smoke. The 11-test delta is exactly what this
changeset added (5 in `test_search.py`, 6 in `test_context.py`) — the counts
were written before the new tests landed and were never refreshed.
`docs/testing.md` is not in the `DOCS_FILES` validated set, so CI cannot catch
the drift.
**Fix:** Update to 1011/971, or drop the per-tier counts and keep only the
tier structure (precise counts rot on every test addition).

### IN-11: DESIGN.md Search Flow documents an invalid bare `sif search` invocation

**File:** `DESIGN.md:257`
**Issue:** The diff rewrote this line (`docsift search` → `sif search`) but kept
the bare form `1. User: sif search "machine learning"`. `search` is a Click
group; this invocation exits with "No such command". The project's own docs
policy (development.md, "Documentation Tests") explicitly rejects bare
`sif search <query>` as stale content requiring `sif search search`,
`sif search query`, or `sif search vsearch`. DESIGN.md is not in the
`DOCS_FILES` validated set, so the docs test cannot flag it.
**Fix:** `1. User: sif search search "machine learning"` (or `query`).

### IN-12: `_collapse_duplicate_path_rows` return value is discarded — destructive merge is silent

**File:** `src/sif/cli/commands/context.py:62` (return; call sites `:113,:128,:199`)
**Issue:** The helper documents and returns the number of duplicate rows
deleted, but all three call sites ignore it. The collapse deletes stored
context content (alias-spelling rows) with no user-visible indication — a user
who re-adds one path and silently loses N legacy rows' text gets an
unqualified "Context updated for path '...'". Either the count should surface
(e.g. "(merged 2 duplicate rows)") or the return value is dead API.
**Fix:** Report it in the confirmation, e.g.
`message = f"updated ({collapsed} duplicate row(s) merged)"` when
`collapsed > 0`, or drop the return value from the helper.

### IN-13: `_seed`/`_path_rows` helpers duplicated verbatim across two test classes

**File:** `tests/unit/cli/test_context.py:537-557` and `:929-949`
**Issue:** `TestContextAddMultiAliasSelfHeal` and `TestContextConfirmationMarkupLiteral`
each define byte-identical `_seed` (real-DB seeding) and `_path_rows`
(raw sqlite3 read-back) helpers — ~20 lines duplicated in one file. Future
fixture changes must be made twice.
**Fix:** Hoist both to module-level functions
(`seed_path_contexts(db_path, spellings, content=...)`,
`read_path_rows(db_path)`) and call them from both classes.
