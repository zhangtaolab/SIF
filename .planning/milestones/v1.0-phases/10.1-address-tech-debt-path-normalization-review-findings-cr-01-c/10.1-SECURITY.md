## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| user input → CLI get/multi-get | untrusted path strings cross into SQL path-equality lookups | filesystem path strings (local, single-user) |
| user input → MCP get_document/get_documents_by_pattern | same, via the MCP tool surface | filesystem path strings |
| stored DB state → schema migration | `create_all()` mutates trigger DDL and (gated) re-derives the FTS index of the user's existing database file on open | user's indexed document content |
| indexed content + user query → XML output | untrusted strings (document titles/paths, the query) cross into machine-consumed XML serialization | arbitrary text incl. control characters |
| CLI process → SQLite file | command lifetime owns a Database connection; conversion changes when the handle is released, not who can reach it | — |
