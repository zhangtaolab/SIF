<objective>
Close the DEBT-PN path-normalization asymmetry (milestone-audit WARNING, "recommended pre-ship fix") and the DEBT-PN-DOC documentation gap, and bring get.py's two WR-01 sites under context-manager Database ownership.

This is the phase tracer: it wires ONE user path end-to-end — user-supplied path (CLI `get`/`multi-get` and MCP `get_document`) → normalize_path canonicalization → DocumentRepository.get_by_path → real SQLite → document content out — and proves the real-temp-DB + CliRunner + symlink-alias test harness the rest of the phase reuses in shape.

Decisions recorded from RESEARCH.md Open Questions (no interactive user check in this chained run):
- OQ2 (lookup order): normalized-only for exact-path lookups — `get_by_path(normalize_path(key), coll.id)`; ID-first and bare-filename lookups stay raw. Probe evidence: scanner-stored rows equal normalize_path(stored).
- OQ2 extension (glob patterns): raw-first-then-normalized — keep the existing raw-pattern match, add a normalized-pattern match for doc.path only. Normalizing the whole pattern is safe because Path.resolve preserves non-existent wildcard tail components (documented in paths.py), but a bare relative pattern like `*.md` must never be resolved against CWD, so the raw match is kept as the first disjunct.
- OQ3 (skills): yes — a one-line note lands in .claude/skills/sif-get/SKILL.md because canonicalization changes user-visible behavior of the documented commands.
- Known limitation carried into docs/tests: stored paths are canonical only down to the collection root; symlinks INSIDE the indexed tree are not resolved by rglob, so exotic in-tree layouts can still miss. Do not promise universal symlink identity.

Spec-less probe fallback skipped: phase has no requirement IDs to probe (visible skip) — no probe-derived predicates generated this run.

Purpose: alias paths (symlinked roots, macOS /tmp aliases) silently return empty today; the fix adopts the locked canonical "same file" definition (normalize_path, STATE.md Phase 05) at the lookup edges, consistent with the searchers' context attachment.
Output: fixed get.py + mcp/backend.py, regression tests with real symlink aliases, regenerated docs, skill note.
</objective>
