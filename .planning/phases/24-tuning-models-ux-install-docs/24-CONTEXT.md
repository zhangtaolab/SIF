# Phase 24: Tuning + Models UX + Install Docs - Context

**Gathered:** 2026-11-16
**Status:** Ready for planning

<domain>
## Phase Boundary

Close v1.2 on measured defaults and generator-verified docs: a held-out-gated chunk size/overlap sweep, a title-breadcrumb per-leg ablation, reliable `sif models pull` / `sif models status`, and uv-first install documentation.

In scope: chunk sweep (per-arm re-chunk + re-embed, isolated arms, embed cost reported), title-breadcrumb experiment (per-leg ablation, duplicate-signal check against title FTS), `sif models` command group + `DEFAULT_MODELS` correction + cache-check fix + canonical cache dir, model status display, uv-first install/degradation/client-config docs, and the `make docs-generate` gate.

Out of scope: further embedder evaluation or default flips (Phase 23 settled Qwen3), GGUF Harrier (MODEL-F1), bge-reranker, full Windows support, non-Markdown formats, multi-embedder serving, and any new retrieval feature.

</domain>

<decisions>
## Implementation Decisions

### Held-out-gated chunk sweep (QUAL-02)
- **D-01:** **Sweep arms are isolated file-backed indexes, one per chunk configuration, each built by a full re-chunk + re-embed.** Fix the embedder to Qwen3-Embedding-0.6B (Phase 23's keep-qwen3 verdict), the parser, the hybrid weights, and the title-FTS behavior; vary only `chunk_size`/`chunk_overlap`. The grid must include the current default (512/128) and stay small (target ≤6 arms; research/planner may refine the exact sizes/overlaps). Report per-arm documents/chunks/vectors, embed wall time, and cache deltas. — **Reversibility:** costly — the grid defines the evidence set for any default change.
- **D-02:** **Use the Phase 23 curated bilingual subset as the controlled corpus and its Qwen3 saved run as the baseline.** The subset (7 Chinese-heavy folders, 498 docs, adequacy en=42/zh=11, held-out N=56) is already the phase's evidence corpus; keeping the embedder and corpus fixed isolates the chunking effect. Record the `N=56 < 101` limitation: a 0.01 win is not admissible; the strict 1/N floor applies. If a larger corpus is supplied, it may replace the subset, but the same Phase 18 gate runs. — **Reversibility:** reversible — evidence can be re-run on a larger corpus.
- **D-03:** **A chunk-default change requires the Phase 18 held-out gate.** Use the paired bootstrap 95% CI + mean Δ ≥ 0.01 + the strict 1/N noise floor; a no-win is recorded with numbers and leaves the default unchanged. Commit a sweep artifact (e.g. `.planning/phases/24-…/bench/chunk-sweep.json`) plus a `docs/benchmarking.md` section with per-arm metrics and the verdict. No ad-hoc or in-sample default change. — **Reversibility:** costly — the published chunking default changes the index layout and re-embed cost.

### Title-breadcrumb experiment (QUAL-03)
- **D-04:** **One breadcrumb arm vs the baseline, per-leg ablation, duplicate-signal check.** Breadcrumb = prepend the document's heading path (H1/H2 chain) to each chunk's *embedding text* only (stored content unchanged); title FTS and BM25 stay as-is. Evaluate with the Phase 18 instrument per leg (title/body/replay) and compare against the Phase 19 title-FTS signal; the breadcrumb must add held-out value beyond the already-indexed title. — **Reversibility:** costly — a changed chunk embed contract affects the index and cache keys.
- **D-05:** **No breadcrumb default without a held-out win.** If the breadcrumb duplicates the title signal or fails the gate, record the rejection with numbers and keep the current chunk embedding unchanged. — **Reversibility:** reversible — evidence-only outcome.

### Models UX (MODELS-01/02)
- **D-06:** **Add a `sif models` command group with `pull` and `status`.** Keep `sif pull` working as a hidden/deprecated alias that routes to `models pull` for one release; the public surface is `sif models pull` / `sif models status`. `docs/cli-reference.md` is generated by `make docs-generate`, never hand-edited. — **Reversibility:** costly — command names are a public CLI contract.
- **D-07:** **`sif models pull [name]` is deterministic, idempotent, and cache-honest.** Default to the configured embedder/reranker/query-expansion model; support `--force`; use the canonical cache dir `<Settings.get_cache_dir()>/models` (platformdirs), recognize/migrate the legacy `~/.sif/models` path; pin the ModelScope revision/path so the same request resolves to the same files; fix the cache check to verify a manifest/content hash (not merely a non-empty directory); stay silent/non-interactive in non-TTY contexts. No new runtime dependency. — **Reversibility:** costly — the cache layout is a user-visible storage contract.
- **D-08:** **`sif models status [--json]` reports configured identity, not just file presence.** Show model id, model type/backend, configured dimension, the persisted embedder identity from `index_meta` when present (source/fingerprint), and a lightweight backend probe (import/availability, no download). Non-TTY output is plain/JSON with no spinners or progress bars. — **Reversibility:** reversible — additive output surface.
- **D-09:** **Correct `DEFAULT_MODELS` to the Qwen3-0.6B family** (embedding `Qwen/Qwen3-Embedding-0.6B` via ModelScope; reranker/query-expansion as documented), retaining Qwen3 as the shipped default embedder. No default-embedder change in this phase; the Phase 23 verdict is authoritative. — **Reversibility:** costly — the download registry names the models users fetch.

### Install docs and the docs-generate gate (DOCS-01)
- **D-10:** **uv-first install docs with an honest degradation matrix.** Primary `uv tool install 'docsif[embed]'`; BM25-only base and `uvx` fallback; Linux CPU-torch index recipe; llama-cpp backend indexes; no-embed-extra → BM25, no-sqlite-vec → vector unavailable, Windows daemon refusal; client config snippets for Claude Desktop/Code (MCP stdio/HTTP) and the plugin. Hand-maintained: `README.md`, `docs/installation.md`, `docs/models.md`, `docs/quickstart.md`; generator-owned `docs/cli-reference.md`/`docs/configuration.md` are regenerated. — **Reversibility:** reversible — docs can be corrected.
- **D-11:** **Every new command and Settings field added here passes `make docs-generate` with a clean diff**, and `tests/test_docs.py` guards the documented install/degradation claims where practical. — **Reversibility:** reversible — docs/tests.

### Evaluation discipline
- **D-12:** **All Phase 24 defaults decisions reuse the Phase 18 instrument and the 0.01/1/N gate.** No default changes from in-sample or ad-hoc runs; a no-win is a first-class recorded outcome. The curated subset's N=56 means a 0.01 effect is inadmissible; artifacts record `min_heldout_for_epsilon_win=101` and the corpus scope. — **Reversibility:** costly — the gate protects published defaults.

### Claude's Discretion
- Exact chunk grid (sizes/overlaps) within the small-grid and include-the-default constraint; overlap of 0 is allowed as an arm.
- Exact breadcrumb rendering (separator, depth, inclusion of H1 vs H1+H2) and the duplicate-signal metric.
- Sweep/breadcrumb artifact schema and table rendering, following `bench`/`eval` conventions.
- `models pull` argument spelling (`[name]` vs `--model`) and the exact status table columns; `sif pull` deprecation wording.
- Whether the chunk sweep and breadcrumb share the Phase 23 scratch root or use separate gitignored scratch subdirs.

<specifics>
## Specific Ideas

- The current chunk defaults are 512 size / 128 overlap; the sweep must include this arm as the baseline.
- `DEFAULT_MODELS["embedding"]` is currently `iic/gte_Qwen2-7B-instruct` (7B), while the settings default is `Qwen/Qwen3-Embedding-0.6B`; the registry is inconsistent and is corrected here.
- `ModelDownloader` caches under a bare md5 prefix in `~/.sif/models` and treats any non-empty directory as cached; the canonical cache dir should follow platformdirs via `Settings.get_cache_dir()`.
- `sif pull` already exists with HF-first/ModelScope-fallback; the new surface is `sif models pull/status`.
- The Phase 23 curated corpus (498 docs, en=42/zh=11, N=56) is the controlled tuning corpus; a 0.01 effect is inadmissible at that N, and the artifact must say so.

</specifics>
