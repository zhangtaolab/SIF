<objective>
Implement the QUAL-03 title-breadcrumb experiment as an embed-text-only overlay: a pure builder and duplicate metrics, a default-off Settings switch wired through the streaming writer and watcher, and a one-arm runbook that evaluates the breadcrumb per leg against the Phase 23 Qwen3 baseline and refuses a default without a held-out win beyond the title signal.

Purpose: Determine with measured evidence whether a title/heading breadcrumb adds retrieval value beyond the already-indexed title, without ever changing the stored index contract on a rejection.
Output: `src/sif/indexing/breadcrumb.py`, the writer/settings/watcher wiring, the breadcrumb decision policy, `scripts/breadcrumb_eval.py`, tests, and regenerated configuration docs.
</objective>
