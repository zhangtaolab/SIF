Resolve the canonical target; when not force and `verify_manifest(target)` succeeds, log and return the target. Otherwise download into a sibling temporary directory named with the target name plus a unique suffix, invoking `snapshot_download` with `model_id`, `revision`, `cache_dir=str(self.cache_dir)`, and `local_dir=str(temporary)`; wrap the call in `suppress_output()` when `is_quiet()`. Write the manifest atomically inside the temporary directory, re-run `verify_manifest` on the temporary directory, then replace the target: when the target exists, rename it to a unique backup, rename the temporary directory to the target, verify the target, and remove the backup only after verification; on any failure remove the temporary directory and restore the backup, and re-raise. Return the target path. A missing `modelscope` import must raise `ImportError` with the message "modelscope is required to download models; install the embed extra: uv tool install 'docsif[embed]'" before any filesystem mutation.
