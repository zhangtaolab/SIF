<objective>
Make reranker cost an explicit, bounded, opt-in behavior.

Purpose: Today rerank is silently ON by default with a Qwen3 model, and `candidate_limit` is a no-op whenever it exceeds `limit`, so the cap never binds. QUAL-05 requires the fast path to be genuinely free and the enabled path to be bounded by a candidate cap and a relative threshold.
Output: `SIF_RERANK_ENABLED` (default false) plus `--rerank`; a pipeline that over-fetches to `max(limit + offset, candidate_limit)` before reranking; `SIF_RERANK_CANDIDATE_LIMIT` (5-50) and `SIF_RERANK_RELATIVE_THRESHOLD` (0 < alpha <= 1) enforced by Pydantic and applied after score normalization; generated config and CLI docs regenerated.
</objective>
