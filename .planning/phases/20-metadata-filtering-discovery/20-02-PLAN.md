Then drop keys named `path` and `mtime` (reserved, D-03); dropping them is shadowing, never a skip. Native top-level keys fill every key the namespace does not define.

    Complete `typed_rows(canonical_json: str)`: `json.loads` the canonical string first, then call `filterable_metadata`, then classify. Ordering is the canonical serialization's sorted key order (`sort_keys=True`), so caps are deterministic. Rules, in this order:
    1. `len(canonical_json.encode("utf-8")) > 65536` → every key is skipped with reason `cap_frontmatter`; record at most the first 64 canonical keys.
    2. Keys after the first 64 → skipped with reason `cap_keys` (do not process them further).
    3. `len(key.encode("utf-8")) > 128` → `cap_key`.
    4. `Mapping`, or a list containing a non-scalar → `nested`.
    5. `None` → `null`.
    6. A list mixing scalar types (including a list of lists) → `mixed_array`.
    7. String longer than 1024 characters → `cap_string`.
    8. List longer than 128 elements → `cap_array`.
    9. Otherwise emit typed rows: `bool` → boolean (check `isinstance(value, bool)` BEFORE `isinstance(value, (int, float))`), `int`/`float` → number, `str` → string; a list of one homogeneous scalar type emits one row per element with `ordinal` 0..n-1, a scalar emits `ordinal` 0.

    Skip accounting is bounded: at most 64 `SkippedKey` rows are returned per document (the same 64-key budget), so a hostile document cannot amplify the sidecar. `replace_from_canonical` deletes then inserts values and skips and returns `(rows_written, skip_rows_written)`.

    `tests/unit/database/test_metadata_values.py` class `TestDerivation`: date-valued key parity (a live `Document` carrying a `datetime` and the same document read back as canonical JSON yield identical rows — the registry-trap regression); numeric typing (`10` and `10.0` produce the same `number_value`; an integer and a float compare equal through the compiler; a boolean row never carries a number); `qmd.metadata` merge wins on collision and merges non-colliding native keys; a document with no namespace is unaffected; `path`/`mtime` frontmatter keys produce no row and no skip row; nested object, null, mixed array, 129-byte key, 1025-char string, 129-element array, 65 keys, and a >64 KB blob each produce the documented reason; skip rows never exceed 64 per document.
