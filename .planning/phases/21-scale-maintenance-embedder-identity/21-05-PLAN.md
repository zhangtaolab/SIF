<objective>
Replace per-collection giant embed transactions with a shared streaming writer: chunk and embed outside any transaction in bounded batches, validate each batch, and commit one short transaction per document that carries chunks, vectors, the shadow row, stats, and (on an empty index) the identity.

Purpose: SCALE-03 is the operational half of the phase: bounded memory and lock hold, resumable exact-set progress, durable prior work on failure, and the qmd #897 garbage-vector guard. The shared writer is the single place completeness, sanity, and shadow maintenance can live, which is what lets the watcher reuse it without divergence.
Output: `src/sif/indexing/embed_writer.py`, the streaming `embed_cmd` with identity enforcement and certification, watcher routing, and the migrated call-shape tests.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| embedding backend -> database | Model output becomes persisted vectors |
| document content -> chunker -> embedder | Untrusted text reaches the model and its output |
| watcher event -> writer | Filesystem events trigger embedding writes |
| identity -> first vector write | The provenance row is created with the first write |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-21-15 | Tampering | batch-boundary garbage vectors | high | mitigate | Structural validation (count/dimension/finite/norm) before persistence; a violation aborts the document and writes nothing (Task 2). |
| T-21-16 | Denial of Service | write-lock hold time and memory | medium | mitigate | Embedding outside transactions, bounded batches, one short per-document commit, collection stats once per collection (Tasks 1-2). |
| T-21-17 | Tampering | identity certification | medium | mitigate | `source="verified"` only on a fresh index's first write or a complete unfiltered zero-failure `--force` (Task 2). |
| T-21-18 | Denial of Service | infinite retry of uncacheable documents | low | accept | A whitespace-only/chunkless document is retried on each run by the existing completeness contract; harmless and bounded by explicit user runs. |
| T-21-SC | Tampering | npm/pip/cargo installs | high | mitigate | No package install occurs in this phase; the legitimacy gate is a no-op. |

## Residual Risk

The D-17 checks are structural, not semantic: finite, unit-norm, correct-dimension garbage can still pass. Respecting chunk/model token limits and Phase 23's bench remain the quality guard. Accepted as the locked floor.
</threat_model>
