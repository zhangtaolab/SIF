## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Personal corpus → arm DBs | The operator's notes are indexed locally; raw content must never be committed. |
| Scratch run → committed artifact/docs | Only aggregate evidence crosses into git. |
| Corpus snapshot → comparison | A content change between arms invalidates the pairing. |
| Adequacy preflight → verdict | An inadequate sample must not become a verdict. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-23-12 | Spoofing | Adequacy preflight / verdict | high | mitigate | The preflight runs before embedding; both `en` and `zh` need >= 10 held-out queries at the cap; an inadequate corpus writes `insufficient-evidence` and exits 3; no post-hoc reclassification is permitted. |
| T-23-13 | Information disclosure | Artifact and docs commit | high | mitigate | The artifact allowlist excludes query text, saved-run records, and absolute paths; corpus labels are basenames; the docs section reproduces aggregate numbers only. |
| T-23-14 | Tampering | Corpus drift between arms | medium | mitigate | `require_matching_corpus` refuses a fingerprint mismatch; a frozen corpus is required and any content change triggers a rerun of both arms, never a fingerprint edit. |
| T-23-15 | Repudiation | Verdict provenance | medium | mitigate | Record both full identities, corpus/query fingerprints, environment/stack, per-arm costs, and the literal rule booleans; the artifact is committed so the decision is auditable. |
| T-23-SC | Tampering | Package installs | high | mitigate | No package is installed by this plan; the only external artifact is the Harrier model repository, recorded by revision and identity fingerprint. |
</threat_model>
