    Define a frozen dataclass `VerdictDecision` with exactly these fields and a fixed-order `to_dict()`: `decision: str`, `required_languages: tuple[str, ...]`, `adequate: bool`, `language_heldout_n: dict[str, int]`, `language_mean_deltas: dict[str, float]`, `overall_n: int`, `overall_mean_delta: float`, `overall_ci_low: float`, `overall_ci_high: float`, `overall_winner: bool`, `ci_excludes_zero: bool`, `mean_delta_at_least_epsilon: bool`, `above_noise_floor: bool`, `per_language_floor_ok: bool`, `reasons: tuple[str, ...]`, `min_heldout_for_epsilon_win: int = MIN_HELDOUT_FOR_EPSILON_WIN`. `to_dict()` emits every field in that order; nested dicts are copied, not aliased.

    Add `_gate_value(gate, field_name)` that accepts a `GateResult` or a `Mapping[str, Any]` and returns the value, raising `ValueError` when the gate is neither or the field is absent. Add `decide_from_gates(heldout, language_heldout, *, required_languages=("en", "zh"), min_language_n=SUPPRESS_BELOW) -> VerdictDecision`:
    - A missing/None overall gate returns `insufficient-evidence` with reason "missing overall held-out gate" and zeroed overall fields.
    - `language_heldout` maps each required language to a gate or None. `adequate` is true only when every required language gate exists and its `n` is at least `min_language_n`. `per_language_floor_ok` is true only when every gate exists and `round(mean_delta, 6) >= -EPSILON`.
    - Compute the literal booleans from the overall gate: `overall_winner = gate.winner`; `ci_excludes_zero = ci_low > 0 or ci_high < 0`; `mean_delta_at_least_epsilon = round(mean_delta, 6) >= EPSILON`; `above_noise_floor = abs(mean_delta) > noise_floor`.
    - Decision precedence: `insufficient-evidence` when not adequate; otherwise `adopt-harrier` only when `overall_winner and per_language_floor_ok`; otherwise `keep-qwen3`.
    - `reasons` names every failed condition: each absent/thin language with its n and the 10 floor, each language mean delta below −0.01, and, when adequate and not adopting, each false literal boolean ("overall held-out winner is false", "95% CI includes zero", "mean delta below 0.01", "mean delta is not strictly above the 1/N noise floor"). A rejection must never be anonymous.

    Add `decide(comparison, *, required_languages=("en", "zh"), min_language_n=SUPPRESS_BELOW)` reading `comparison.splits["heldout"]` and `comparison.language_splits[lang]["heldout"]`; raise `ValueError` naming the missing split when `splits` lacks `heldout`. Add `decide_from_payload(payload, ...)` reading the CLI comparison object's `payload["splits"]["heldout"]` and `payload.get("language_splits", {})`; raise `ValueError` when `payload` or `splits` is not a mapping, and treat a missing `language_splits` as `{}` (which yields `insufficient-evidence`, not an exception).

    Add the first tests: build real `noise_gate` gates for an adopt case (overall N=101, mean delta 0.02, CI excluding zero; en and zh held-out N>=10 with non-negative mean deltas) and assert `decide_from_gates`, `decide` (with `types.SimpleNamespace(splits=..., language_splits=...)`), and `decide_from_payload` all return `adopt-harrier`. Assert `MIN_HELDOUT_FOR_EPSILON_WIN == 101` and the fixed `to_dict()` key order.
