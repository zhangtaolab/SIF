| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-23-01 | Tampering | `eval_group` `--require-language` | low | mitigate | `click.Choice(LANGUAGES)` rejects unknown values before sampling; the flag only narrows widening, never alters a saved query set; no SQL is built from it. |
| T-23-02 | Spoofing | `ComparisonReport.language_splits` | high | mitigate | Absent languages produce no key and empty splits produce `n=0, sufficient=False`; plan 23-02's verdict treats a missing or thin gate as `insufficient-evidence`, so a fabricated zero row cannot authorize a default change. |
