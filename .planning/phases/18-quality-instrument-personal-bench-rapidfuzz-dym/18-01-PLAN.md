<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| SQLite `documents` -> personal-bench domain | Stored titles/content/checksums are read into the measurement path; content is transient and must never reach output. |
| personal-bench data -> CLI table | Titles and paths are user/vocab-derived strings rendered through Rich markup. |
| CLI arguments -> search options | `-c/--collection` names and `-n/--limit` cross into repository/searcher calls. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-18-01 | Spoofing | `eval.py` table cells | medium | mitigate | Truncate then `rich.markup.escape()` every title/path-derived cell (the `suggest.py::_cell` convention, T-15-06); tests assert bracket text renders literally. |
| T-18-02 | Denial of Service | `load_documents` / synthesis | medium | mitigate | Iterate the cursor, select only needed columns, cap the sample at 250 documents and 500 queries, and never materialize `fetchall()` of the corpus. |
| T-18-03 | Tampering | collection scope resolution | low | mitigate | Reuse `CollectionRepository.get_by_name` / parameterized SQL only; never interpolate collection names into SQL. |
| T-18-SC | Tampering | dependency installs | high | mitigate | This plan installs no package. The phase's only new package (rapidfuzz) is gated by the Plan 04 blocking human checkpoint and the Plan 04 lock verification. |

**Residual risk:** the personal bench reads document bodies locally. Content is retained only for the synthesis pass and is never serialized; the saved-run writer (Plan 03) must enforce the same rule.
</threat_model>
