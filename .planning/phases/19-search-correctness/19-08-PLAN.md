| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-19-18 | Tampering | title-FTS rebuild / documents_fts_v | high | mitigate | Drop the vocab before the FTS table, populate exactly once with `('rebuild')` (no `INSERT ... SELECT` seed beside it), recreate vocab and triggers; the migration test asserts counts, single-token match cardinality, and post-delete unmatchability — not just `PRAGMA integrity_check`, which passes with duplicates |
| T-19-19 | Tampering | weighted bm25 SQL | high | mitigate | Content/title weights and the min_score threshold are bound parameters; the FTS table name is a literal; no user text reaches the weight expression |
| T-19-20 | Denial of Service | create_all on a populated database | low | accept | The rebuild runs once per database, gated by one `sqlite_master` read; FTS5 'rebuild' is the official bulk command and is bounded by index size |
| T-19-SC | Tampering | npm/pip/cargo installs | high | mitigate | No install in this plan; no dependency or lockfile change |
