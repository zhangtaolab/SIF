<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| persisted convention marker -> index-writing pass | A missing, stale, or forged marker decides whether every document is re-parsed |
| watcher event path -> embed leg | Watch events select documents for chunk/vector writes |
| indexing progress callback -> CLI/watch/MCP hosts | The migrate notice crosses the presentation-free event protocol |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-19-03 | Tampering | `index_meta` convention marker / `update_collection` | medium | mitigate | Marker is written only after a zero-failure pass, inside the same short transaction discipline as other writes; per-collection keys isolate `-c` and watch reconciles; tests cover the failure path |
| T-19-04 | Repudiation | metadata fast path in `_process_file` | high | mitigate | Only exact stored-content equality takes the fast path; body changes still purge chunks and embeddings; watcher embed selection comes from the explicit `reindexed_paths` signal; regression tests assert chunk/vector counts |
| T-19-05 | Denial of Service | forced migration on a large collection | low | accept | The migration is one pass over the scanned files with per-file short transactions and is resumable; the notice names the count so the user sees the cost |
| T-19-SC | Tampering | npm/pip/cargo installs | high | mitigate | No install in this plan; no dependency or lockfile change |
</threat_model>
