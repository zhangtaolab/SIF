## Implementation Decisions

### Cleanup scope
- **D-01:** **Audit headline pass** — close 11-WR-03, 14-WR-02/04 (duplicate titles, one defect), 14-WR-03 (read-side remainder), W-1, W-3. All warning-severity; exactly the audit's cleanup recommendation. Info findings and 11-WR-04 stay open for a later pass. The convention-wide error sweep (D-02) additionally addresses the traceback half of 15-IN-06 as a side effect.

### CLI error conventions
- **D-02:** **Convention-wide sweep** — fix every unwrapped `db.init_schema()` site (~28 across `collection`/`context`/`get`/`ls`/`suggest`/`search`/`index`/`watch`/`bench`) plus the `vsearch`/`query` searcher constructions (`search.py:678` `VectorSearcher`, `:934` `SearchPipeline`). A shared boundary mechanism is preferred over 30 copy-paste try/excepts — the mechanism's shape is the planner's call. Not just the 4 sites named in the findings: the phase title says "conventions", and identical violations elsewhere leave the convention broken.
- **D-03:** **Remedy hints for known failure classes** — sqlite-vec absent → how to install it; DB open/schema failure → name the DB path + likely cause (permissions/disk/corruption). Matches the project's remedy-hint culture (Phase 14 D-13 "run 'sif embed' to refresh", over-cap "run sif index update"). Unknown exceptions keep plain messages.
- **D-04:** **Known classes only, no catch-all** — catch the foreseeable user-facing failure classes (`sqlite3.Error`, `OSError`, searcher-construction `RuntimeError`) and map to `click.ClickException`. Unexpected bugs still show full tracebacks (useful for issue reports). No CLI-wide catch-all boundary that would mask programmer errors.

### Cache TTL (14-WR-03 remainder)
- **D-05:** **Instant-compare in `get()`** — fetch the row by key, parse `expires_at`, compare instants; legacy naive-local strings interpreted as system-local via `astimezone` — exactly the semantics `clear_expired()` already locked in (WR-09 fix, commit 67d8644). One shared expiry helper serves both methods. No migration, no data rewrite, no discarding still-valid legacy cache entries. — **Reversibility:** reversible — local read-path change, no schema or data touched.

### Watch-host enqueue API (W-3)
- **D-06:** **Narrow reconcile-intent public API** — e.g. `enqueue_reconcile(collections)` on `FileWatcher`; keeps `FoldResult` and the queue's tuple protocol private. Matches every existing use: the serve-first reconcile in `watch_host.py:100` and the watcher's own two internal reconcile sites (`watcher.py:572`, `:637`) route through it too. Exact name/signature = Claude's discretion. No generic `enqueue(job)` — the internal job shape must not become a public contract. — **Reversibility:** costly — a public method on the class all three watch hosts share; renaming/removing it later touches every host plus tests.

### Carried forward (pre-decided — do not re-litigate)
- **ClickException for user-facing CLI errors** (CLAUDE.md Error Handling Conventions). Core `HybridSearcher.search()` stays fail-fast; the BM25 degradation carve-out is **MCP-boundary-only** (WR-08, user-decided 2026-11-11). `vsearch` is pure vector — it cannot degrade; its fix is presentation-only.
- **Pragma recipe non-divergence** — the integration audit proves WAL/busy_timeout/synchronous=NORMAL executes ONLY in `database/factory.py`. W-1 must REUSE the factory, never copy pragmas into `embedding/cache.py`.
- **Embedding cache stays fail-soft and separate** — cache failures must never break embedding; the cache DB remains its own file (W-1 hardens the connection, not the architecture).
- **WR-09 expiry semantics locked** — legacy naive-local = system-local via `astimezone`; NULL/unparseable expiries are never deleted by cleanup.
- **Serve-first ordering preserved** (13-D04) — the public enqueue API must not change startup semantics: reconcile jobs are the watcher's first queued jobs; initialize/lifespan never wait on indexing.
- Zero new runtime dependencies; generator-owned docs (`make docs-generate` — no flag/settings changes expected, so docs likely untouched); full quality suite per plan (pytest fail_under=90, ruff, ty); deterministic test culture.
- **Ledger-closure culture** — disposition rows go open→fixed with evidence in the Source cell (the quick-task three-edit precedent); closing a finding means the ledger says so, not just the code.
