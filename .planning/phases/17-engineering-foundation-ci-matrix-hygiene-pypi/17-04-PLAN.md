## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| local repo -> hc remote (yoga) | Repo code executes on a user machine over a remote-control channel; commands must be fixed, argv-only, and non-destructive. |
| smoke script -> sif CLI | The script drives the product with a temp database; a mistaken path or argument could touch the real index. |
| smoke script -> subprocess | Untrusted output is parsed; matchers must not execute or echo anything sensitive. |
