<objective>
Give the MCP `query` full CLI pipeline parity and make the embedder lazy, single-attempt, and quiet so the stdio protocol channel stays clean from cold start through the first vector query.

Purpose: MCP-05 and MCP-06 close the behavioral gap between `sif search query` and the agent surface. The embedder must not load at startup (fast, quiet hosts), must load once under concurrency, and must degrade honestly on failure. The pipeline components already exist; this plan wires them rather than reimplementing them.
Output: a lazy `_ensure_embedder`, loaded-dimension handling, hoisted parity components, opt-in rerank with soft degradation, `set_quiet` at the roots, and the lazy/stdout regression batteries.

| server process -> stdout | stdio mode uses fd 1 as the protocol channel |
