<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser / network -> loopback HTTP | Host and Origin headers are attacker-controlled |
| `/health` -> parent FastAPI app | It sits outside the SDK mount and needs its own Host check |
| PID file -> OS signal | A tampered or stale PID could target the wrong process |
| Watch daemon <-> MCP daemon | Two lifecycle artifacts share one index |
| CLI flags -> security posture | `--allowed-hosts` can widen the allowlist |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-22-07 | Spoofing | DNS rebinding against `/mcp` and `/health` | high | mitigate | Explicit `TransportSecuritySettings` on every bind (never None, never `*`); Host 421 / Origin 403 / Content-Type 400 tests; narrow `/health` Host guard; non-loopback warning without widening (Task 1). |
| T-22-08 | Spoofing / Denial of Service | PID tampering and `--stop` | high | mitigate | 0600 write-temp-rename; fail-closed marker-aware corroboration; MCP marker distinct from watch; `--stop` only signals a corroborated MCP daemon; stale files are removed without a signal (Tasks 2-3). |
| T-22-19 | Denial of Service | daemon bind failure | medium | mitigate | Arm on readiness, bind after arming, remove the PID in `finally`, log and exit non-zero; test simulates the failure (Task 3). |
| T-22-SC | Tampering | npm/pip/cargo installs | high | mitigate | No package install in this plan; the dependency gate is covered by 22-01. |
</threat_model>
