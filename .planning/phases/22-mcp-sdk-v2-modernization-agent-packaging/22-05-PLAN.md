<objective>
Make MCP output citation-grade: snippet line windows, stored content hashes, full and ranged document line ranges, and additive structured fields — without changing CLI JSON or the frozen metadata envelope.

Purpose: MCP-03 is what turns search results into verifiable citations. The snippet window already exists in the pipeline; this plan exposes its line range instead of rescanning, and adds the stored checksum for drift detection. The `sif-cite` skill (22-06) depends on these fields.
Output: range-returning snippet extraction, dataclass-only line fields, MCP citation fields, one batched checksum lookup, full/ranged `get` ranges, and the citation/envelope regression battery.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| indexed document text -> snippet/line range | Content can contain misleading line breaks or truncation |
| stored checksum -> MCP content_hash | A wrong hash would hide citation drift |
| MCP client -> `docs://` resource / `get` | Client-supplied doc id or path could attempt traversal |
| metadata envelope -> agent filter discovery | A changed envelope would break the frozen Phase 20 contract |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-22-11 | Tampering | `docs://{doc_id}` and `get` path resolution | high | mitigate | SDK `ResourceSecurity` rejects `..`, absolute paths, and null bytes; the backend resolves ids/paths through repositories, never the filesystem; the `get` tool remains the citation surface (Tasks 2-3). |
| T-22-12 | Repudiation / Tampering | citation drift and stale hashes | medium | mitigate | `content_hash` is the stored checksum, fetched once per page; `vectors_stale` rides through; the `sif-cite` skill requires `get` before citing; tests pin the stored-hash equality (Tasks 2-3, 22-06). |
| T-22-21 | Information Disclosure | snippet/content projection | low | mitigate | Only indexed content is returned; no new path or filesystem surface; line ranges are derived from the already-fetched content (Tasks 1-2). |
| T-22-SC | Tampering | npm/pip/cargo installs | high | mitigate | No package install in this plan; dependency gate covered by 22-01. |
</threat_model>
